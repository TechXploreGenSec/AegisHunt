Startup gate for new engagements (not resumes): verifies every layer the hunt depends on — agents registered, per-agent tool permissions (including question-denied), skills installed, methodology source + index readable, graph reachable, audit log writable end-to-end, required env present. Throws one consolidated error naming every gap and its fix; a clean run returns sufficient:true. Coordinator calls this first on a fresh engagement and resolves all failures before scoping.
